Power BI Supply Chain Analytics Dashboard

Overview

This Power BI dashboard serves as the business intelligence and reporting layer of the **AWS Supply Chain Analytics Pipeline**.

The dashboard provides interactive analysis of supply chain performance across revenue, orders, delivery performance, shipment completeness, product categories, warehouse locations, customer segments, and order status.

The curated supply chain dataset is produced through the AWS data pipeline and used in Power BI to transform processed data into business insights.

---

Dashboard KPIs

The dashboard contains six primary KPI cards:

| KPI | Description |
|---|---|
| Total Revenue | Total revenue generated across all order lines |
| Total Orders | Number of unique customer orders |
| Average Order Value | Average revenue generated per order |
| Average Delivery Days | Average number of days required for delivery |
| Orders Missing Shipment | Number of orders without associated shipment information |
| Missing Shipment % | Percentage of total orders missing shipment information |

The full dataset currently produces approximately:

- Total Revenue: 29.62M
- Total Orders: 9K
- Average Order Value: 3.34K
- Average Delivery Days: 4.46
- Orders Missing Shipment: 2K
- Missing Shipment Percentage: 20.1%

DAX Measures

1. Total Revenue

Calculates total revenue from all order lines.

```DAX
Total Revenue =
SUM(order_analytics[line_revenue])
```

---

2. Total Orders

Calculates the number of unique orders.

```DAX
Total Orders =
DISTINCTCOUNT(order_analytics[order_id])
```

---

3. Average Order Value

Calculates the average revenue generated per order.

```DAX
Average Order Value =
DIVIDE(
    [Total Revenue],
    [Total Orders],
    0
)
```

---

4. Average Delivery Days

Calculates the average delivery duration across available shipment records.

```DAX
Average Delivery Days =
AVERAGE(order_analytics[delivery_days])
```

---

5. Orders Missing Shipment

Identifies unique orders where shipment information is unavailable.

```DAX
Orders Missing Shipment =
CALCULATE(
    DISTINCTCOUNT(order_analytics[order_id]),
    ISBLANK(order_analytics[shipment_id])
)
```

---

6. Missing Shipment Percentage

Calculates the percentage of orders without associated shipment information.

```DAX
Missing Shipment % =
DIVIDE(
    [Orders Missing Shipment],
    [Total Orders],
    0
)
```

The measure is formatted as a percentage in Power BI.

Interactive Slicers

The dashboard contains interactive slicers that allow users to dynamically filter the report.

Warehouse City

Filters dashboard metrics and visualizations based on warehouse location.

Order Status

Filters results based on the current order status.

Product Category

Allows users to analyze specific product categories.

Order Date

Provides a date-range selector for analyzing supply chain performance during a selected period.

---

Cross-Filtering

Power BI automatically propagates slicer selections across the dashboard.

For example, selecting a warehouse such as **St. Louis** dynamically recalculates:

- Total Revenue
- Total Orders
- Average Order Value
- Average Delivery Days
- Orders Missing Shipment
- Missing Shipment %
- Revenue by Category
- Monthly Revenue
- Order Status Distribution
- Customer Segment Revenue

This allows users to perform interactive supply chain analysis without writing additional SQL queries.

---

Data Quality Monitoring

The dashboard also exposes shipment completeness as a business data-quality metric.

Two KPIs are used:

Orders Missing Shipment

Measures how many orders do not have associated shipment information.

Missing Shipment %

Measures the proportion of total orders affected by missing shipment information.

Instead of removing these records from the reporting layer, the dashboard makes the issue visible so users can understand the completeness of the underlying supply chain data.

Additional reconciliation and validation queries are documented in:

```text
sql/data_quality_checks.sql
```

Analytics Architecture

The Power BI dashboard represents the final analytics layer of the supply chain pipeline.

```text
Source Supply Chain Data
        |
        v
    Amazon S3
        |
        v
    AWS Glue
        |
        v
   PySpark ETL
        |
        v
Processed / Curated Parquet
        |
        v
   Amazon Athena
        |
        v
     Power BI
        |
        v
Interactive Supply Chain Dashboard
```

Project Purpose

The objective of this project is to demonstrate an end-to-end analytics workflow where raw supply chain data is processed through AWS services, transformed into analytics-ready datasets, validated for data-quality issues, queried through Amazon Athena, and presented through an interactive Power BI dashboard.

The project combines **data engineering, data quality, SQL analytics, and business intelligence** within a single portfolio project.
